I asked the AI agent on my laptop for a beach collage, sent to my phone. It used my actual apps.

No API, no plugin for Photos or Telegram. Claude Code drives them through agent-desktop, an open-source CLI from @[Vercel](urn:li:organization:16181286) Labs that reads each app's accessibility tree, the same structure a screen reader uses: it finds "8 Photos Selected", clicks "Export", pastes the collage into Telegram and checks the caption before pressing Enter.

It wasn't smooth at first. Telegram's Send button ignores clicks, the caption field hides its own text, and a save dialog will happily drop your files in the wrong folder. Each of those turned into a rule the agent now follows.

What I take from it: if an app is accessible, it's a tool. And I suspect the apps an agent can't see are largely the ones screen-reader users struggle with too. That's what I want to measure next.

🔧 agent-desktop: https://github.com/vercel-labs/agent-desktop

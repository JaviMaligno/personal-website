The difference between a toy and a production system isn't better code.

The agent writes decent code either way. What changes is whether anything is checking it.

Toy → Production
• runs on my laptop → lives on the internet
• key inside the code → key in a secret manager
• data in a local file → remote database with backups
• anyone can call the API → auth and limits in place
• nothing written down → documentation the agent reads
• nobody checks this box → every box has someone checking it

Every box has someone checking it. That's the one that separates the two columns.

Production isn't a level of skill you reach. It's that no category is left unchecked by anyone — you, a test, a service, or another person — and that you know which is which.

Which leaves exactly one problem: to notice a box is empty, you have to know it exists.

That's the part nobody teaches. Agents answer questions well. They're much worse at telling you which question you should have asked.

Flipbook has no HTML. No DOM. No rendered components.

Every pixel you see — including the text — is generated frame-by-frame by a video diffusion model streaming over a WebSocket.

It launched in April 2026 from a team of ex-OpenAI, ex-Humane, ex-Apple engineers. The interface runs on LTX Video, an open-source diffusion transformer optimized to stream at 1080p/24fps from serverless GPUs. When you "click," the model generates the next frames.

DeepMind is doing the same thing at world-model scale with Project Genie — you type a prompt and walk around a generated world that renders as you move.

Are these useful products yet? Barely. Flipbook is experimental. Genie loses coherence after a minute or two.

But the direction is clearer than the products: the rendered output of an application is becoming a model inference, not a tree of components.

Think about what that means alongside the other end of the stack, where code is becoming markdown skills. The layer we used to call "software" is being squeezed from both ends.

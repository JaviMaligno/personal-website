# Mentoría — material comercial (movido)

El diseño de la oferta y el guion del taller **ya no viven aquí**. Están en el
repositorio privado `JaviMaligno/javieraguilar-business`, porque contienen
precios, estrategia de tarifas, segmentación del comprador y guiones de entrega
— cosas que un cliente potencial no debería leer antes de una negociación.

Este repositorio es público. Lo que se queda aquí es contenido y memoria de
diseño de artículos, que no revela nada comercial.

**Nota:** esos documentos estuvieron en este repositorio público entre el
2026-08-04 y el 2026-08-10, así que siguen en el historial de git. Sacarlos de la
rama reduce la exposición futura, no la pasada — el mismo principio que el
artículo aplica a las claves de API.

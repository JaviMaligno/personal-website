# Capturas de revisión — paleta mate + método/oferta

Capturas antes/después para revisar la PR sin levantar el proyecto. Son
artefactos de revisión, no contenido del sitio: **este commit se puede
descartar antes de mergear** sin tocar el resto de la rama.

Tomadas con Chromium a 1360×820, español, servidor de desarrollo. El "antes"
es el estado de `main`.

|---|---|
| `palette-hero-{before,after}.png` | Hero — el halo de los botones y el fondo |

Nota: las capturas se hicieron con la cabecera en `position: static` para que
no tapara el contenido, y sin las fuentes de Google (bloqueadas en el entorno
de captura), así que la tipografía es la de respaldo del sistema. Los colores
sí son los reales.

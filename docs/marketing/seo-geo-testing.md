# Testing Tools

## Traditional SEO

1. Lighthouse (built into Chrome DevTools) or use CLI
    - `npx lighthouse https://www.javieraguilar.ai --view`
2. Google Search Console - Submit sitemap, monitor indexing
    - https://search.google.com/search-console
3. Rich Results Test - Check structured data
    - https://search.google.com/test/rich-results

## GEO (Generative Engine Optimization)

Testing if AI can find and cite your content:

1. Ask AI search engines directly:
    - https://perplexity.ai - Ask "Who builds MCP servers for Bitbucket?"
    - https://chat.openai.com - Same query
    - https://you.com - Test your discoverability
2. Check if your content is cited - After a few weeks of indexing, search for topics you've written about

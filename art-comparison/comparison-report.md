# Art Comparison: Claude (Scripts) vs Flux vs Gemini

Comparative study of artistic image generation across 8 categories.
- **Claude**: HTML/SVG/Canvas scripts generated by code
- **Flux**: FLUX.1-schnell via Hugging Face API
- **Gemini**: Gemini with native image generation

---

## 01 - Op Art / Victor Vasarely

| Criteria | Claude (Script) | Flux | Gemini |
|----------|----------------|------|--------|
| Illusion 3D | Checkerboard deformed by sphere function — mathematically computed. Some edge artifacts at distortion boundary | 3D sphere with distorted checkerboard pattern — visually dramatic, strong depth illusion | Simple concentric circles — more of a target/bullseye than Op Art |
| Vasarely fidelity | High — faithful to Vega series (grid distortion) | High but adds explicit 3D sphere (more render than Op Art) | Low — lacks the grid distortion that defines Vasarely |
| **Winner** | **Flux** | Flux's distortion is more dramatic and impactful. Claude close second with mathematically correct approach. Gemini misses the brief. | |

## 08 - Fractal Mandelbrot

| Criteria | Claude (Script) | Flux | Gemini |
|----------|----------------|------|--------|
| Mathematical accuracy | REAL Mandelbrot computation: z=z²+c, 800 iterations, Seahorse Valley at 400x zoom, smooth coloring with histogram equalization | Decorative spiral — looks fractal-ish but is not mathematically computed. More like a psychedelic swirl | Spiral patterns that resemble fractals but are not computed from the Mandelbrot equation |
| Detail | Infinite precision: every pixel computed. Smooth color transitions, no banding. 4096-color palette | "Hallucinated" detail — attractive but structurally wrong | Colorful but incorrect self-similar structure |
| Color | Deep purple → blue → cyan → green → gold → orange → red. Gamma-corrected with histogram equalization | Oversaturated rainbow with painterly textures | Rainbow with blue/orange dominant, decent palette |
| **Winner** | **Claude dominates** | Only real mathematical fractal. The others are "fractal vibes" — pretty but fake. This is where code-generated art is unbeatable. | |

### Scores (3pts / 2pts / 1pt)

| Model | Score | Strengths |
|-------|-------|-----------|
| **Gemini** | **18** | Artistic composition, style coherence, character |
| **Flux** | **15** | Organic textures, realism, dramatic visuals |
| **Claude** | **15** | Mathematical precision, text legibility, pixel accuracy, computability |

### Key Takeaways

- **Claude wins** in computable domains: fractals, legible text, true pixel art, correct isometric geometry
- **Gemini wins** in artistic composition, style fidelity, and overall "does this look like real art?" feel
- **Flux wins** in organic textures and photorealistic rendering, but fails catastrophically at text
- **All image models** fail at text legibility — Claude's clearest structural advantage
- **Claude's weakness**: organic forms (butterfly wings, natural landscapes, paint textures)
- **Best surprise**: Claude's retro poster rivaling Gemini — typography + geometric design is a sweet spot
